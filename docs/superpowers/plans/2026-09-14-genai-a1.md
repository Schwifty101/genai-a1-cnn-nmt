# GenAI A1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, train and analyze two deep-learning systems — a custom CNN that classifies chest X-rays into COVID19/NORMAL/PNEUMONIA, and a vanilla-RNN English→Urdu translator — and deliver both as one reproducible repo plus one IEEE two-column report.

**Architecture:** A single `src/` package with a shared `common/` layer (seeding, device, metrics, plots, generic trainer) and two independent study packages, `q1_cnn/` and `q2_rnn/`. Every stage is a CLI script driven by a YAML config; every stage writes machine-readable artifacts into `results/`; the LaTeX report consumes only those artifacts. Nothing is hand-transcribed between code and report.

**Tech Stack:** Python 3.13 (uv), PyTorch 2.14 + torchvision 0.29 on Apple MPS, torchinfo, scikit-learn, pandas, matplotlib/seaborn, Pillow + imagehash, openpyxl, sacrebleu, pytest, tectonic (LaTeX).

**Spec:** `docs/specs/2026-09-14-genai-a1-design.md`

## Global Constraints

Every task's requirements implicitly include this section. Copied verbatim from the spec.

- **SEED = 42** everywhere — `random`, `numpy`, `torch`, `torch.mps`, DataLoader `generator` and `worker_init_fn`. Defined once in `src/common/seed.py`; no module defines its own seed constant.
- **Splits are 80/10/10**, stratified where labels exist, produced once and persisted to a CSV manifest. Every downstream script reads the manifest. No script re-splits.
- **Framework is PyTorch.** Device selection lives only in `src/common/device.py::pick_device`. No module calls `torch.device("mps")` directly.
- **Q1 primary model is the custom CNN (`PneumoNet`).** VGG16 and ResNet50 are comparison baselines only and are never presented as the primary result.
- **Q2 uses `nn.RNN` only.** `nn.LSTM`, `nn.GRU`, attention modules and Transformer components must not appear anywhere under `src/q2_rnn/`. This is enforced by an automated test.
- **Augmentation applies to the training split only.** Val and test transforms are resize + normalize, nothing else.
- **No fabricated numbers.** Every report table and figure is generated from a file in `results/`. If a run did not happen, it does not appear.
- **Special token IDs are fixed**: `<pad>=0`, `<sos>=1`, `<eos>=2`, `<unk>=3`.
- **Model selection metric for Q1 is validation macro-F1** (not accuracy — the classes are imbalanced). For Q2 it is validation loss.
- **Image size** is 224x224 for all full runs and 128x128 for grid-search proxy runs.
- **Python 3.13** via `uv`; dependencies pinned in `pyproject.toml`.
- All paths in code are relative to the repo root and resolved via `pathlib`, never hardcoded absolutes.

## A Note On Code In This Plan

Tasks below specify **exact function and class signatures, exact return-value
shapes, and exact test code**. Function bodies for standard, unambiguous work
(plot rendering, argparse wiring, file I/O) are specified by contract rather
than transcribed line-by-line; the tests are the binding definition of correct
behavior. Where a body is subtle and easy to get wrong — the collate shifting,
the dedup logic, the encoder packing, the L1 penalty — the code is given in

```python
"""The single source of randomness control for the whole project."""

from __future__ import annotations

import os
import random

import numpy as np
import torch

SEED = 42


def set_seed(seed: int = SEED) -> None:
    """Seed every RNG this project touches."""
    os.environ["PYTHONHASHSEED"] = str(seed)
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    if torch.backends.mps.is_available():
        torch.mps.manual_seed(seed)
    if torch.cuda.is_available():
        torch.cuda.manual_seed_all(seed)


def seed_worker(worker_id: int) -> None:
    """DataLoader worker_init_fn that keeps worker RNGs deterministic."""
    worker_seed = torch.initial_seed() % 2**32
    np.random.seed(worker_seed)
    random.seed(worker_seed)


def make_generator(seed: int = SEED) -> torch.Generator:
    """A seeded generator for DataLoader shuffling."""
    generator = torch.Generator()
    generator.manual_seed(seed)
    return generator
```

```python
"""The single place in the project where a torch device is chosen."""

from __future__ import annotations

import torch


def pick_device(prefer: str = "auto") -> torch.device:
    """Return the compute device.

    `prefer` is one of "auto", "mps", "cpu". "auto" selects MPS when it is
    available and falls back to CPU otherwise.
    """
    if prefer not in {"auto", "mps", "cpu"}:
        raise ValueError(f"prefer must be auto|mps|cpu, got {prefer!r}")
    if prefer == "cpu":
        return torch.device("cpu")
    if prefer == "mps":
        if not torch.backends.mps.is_available():
            raise RuntimeError("MPS requested but not available")
        return torch.device("mps")
    return torch.device("mps" if torch.backends.mps.is_available() else "cpu")
```

- [ ] **Step 4: Implement `src/common/metrics.py`**

Use `sklearn.metrics.precision_recall_fscore_support` with `labels=range(len(class_names))` and `zero_division=0` for the per-class block, `confusion_matrix(..., labels=range(n))` for the matrix, and `roc_auc_score` per class in one-vs-rest form built from `(y_true == i).astype(int)` against `y_prob[:, i]`. A class with only one present label yields `float("nan")` for its AUC; `auc_macro` is the mean of the non-NaN entries. `macro` is the unweighted mean over classes. Cast the confusion matrix with `.astype(int).tolist()` and every float with `float(...)` so the dict is JSON-serializable.

`metrics_to_markdown` renders a GitHub-flavored table: one row per class with precision/recall/F1/support/AUC, then a `**Macro**` row, then a line with overall accuracy and macro AUC.

- [ ] **Step 6: Implement `src/common/trainer.py`**

The loop, per epoch: train pass (`model.train()`), then `evaluate_model` on the validation loader, then metric computation via `compute_classification_metrics` to obtain `val_macro_f1`, then scheduler step, then early-stopping bookkeeping.

The L1 penalty and gradient clipping go inside the training pass, in this order:

```python
loss = criterion(logits, yb)
if cfg.l1_lambda > 0:
    l1 = sum(p.abs().sum() for p in model.parameters() if p.requires_grad)
    loss = loss + cfg.l1_lambda * l1
optimizer.zero_grad(set_to_none=True)
loss.backward()
if cfg.grad_clip is not None:
    torch.nn.utils.clip_grad_norm_(model.parameters(), cfg.grad_clip)
optimizer.step()
```

Early stopping compares the monitored value against the best seen so far using `>` when `cfg.mode == "max"` and `<` when `"min"`. On improvement: reset the patience counter, record `best_epoch` and `best_score`, and `torch.save(model.state_dict(), cfg.ckpt_path)` when a checkpoint path is set. When the counter reaches `cfg.patience`, break and set `stopped_early=True`. After the loop, reload the best checkpoint into the model when one was written, so the returned model is the best model and not the last.

`evaluate_model` runs under `torch.no_grad()` with `model.eval()`, accumulates logits, applies `softmax(dim=1)` for `y_prob`, `argmax` for `y_pred`, and returns numpy arrays on CPU.

- [ ] **Step 3: Implement `src/q1_cnn/data_prep.py`**

Key implementation notes, in the order the pipeline runs:

`is_corrupt` must both `verify()` and reload, because `verify()` alone misses truncated pixel data:

```python
def is_corrupt(path: Path) -> bool:
    try:
        with Image.open(path) as im:
            im.verify()
        with Image.open(path) as im:
            im.load()
        return False
    except Exception:
        return True
```

`scan_images` iterates `sorted(root.glob("Data/*/*/*"))` so ordering is deterministic, keeps only files whose suffix is in `{".jpg", ".jpeg", ".png"}`, and derives `label` from the parent directory name and `source_dir` from its grandparent.

`deduplicate` sorts by `path` first so the kept representative never depends on input order. Exact duplicates go first via `drop_duplicates(subset="md5", keep="first")`. Near-duplicate removal then compares each surviving row against the already-kept rows using `imagehash.hex_to_hash(a) - imagehash.hex_to_hash(b)`, which returns the Hamming distance. For ~6k rows this quadratic scan is a few seconds and is bucketed by the first 4 hex characters to keep it well under a minute.

`build_manifest` chains download → scan → deduplicate, writes the CSV with `index=False`, and writes the merged report JSON containing `total_found`, `corrupt`, `exact_duplicates`, `near_duplicates`, `kept`, and a `class_counts` mapping.

**PneumoNet architecture** — exactly this, four blocks then a global-average-pooled head:

```python
def _block(in_ch, out_ch):
    return nn.Sequential(
        nn.Conv2d(in_ch, out_ch, 3, padding=1, bias=False),
        nn.BatchNorm2d(out_ch),
        nn.ReLU(inplace=True),
        nn.Conv2d(out_ch, out_ch, 3, padding=1, bias=False),
        nn.BatchNorm2d(out_ch),
        nn.ReLU(inplace=True),
        nn.MaxPool2d(2),
    )


class PneumoNet(nn.Module):
    def __init__(self, num_classes=3, dropout=0.3, in_channels=3):
        super().__init__()
        self.features = nn.Sequential(
            _block(in_channels, 32),
            _block(32, 64),
            _block(64, 128),
            _block(128, 256),
        )
        self.pool = nn.AdaptiveAvgPool2d(1)
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Dropout(dropout),
            nn.Linear(256, 256),
            nn.ReLU(inplace=True),
            nn.Dropout(dropout),
            nn.Linear(256, num_classes),
        )

    def forward(self, x):
        return self.classifier(self.pool(self.features(x)))
```

**Baseline construction rules:**
- `vgg16_frozen` / `resnet50_frozen`: load `torchvision.models.vgg16(weights=VGG16_Weights.IMAGENET1K_V1)` / `resnet50(weights=ResNet50_Weights.IMAGENET1K_V2)`, set `requires_grad=False` on every backbone parameter, then replace the final classifier layer with a fresh `nn.Sequential(nn.Dropout(dropout), nn.Linear(in_features, num_classes))`. Only the new head has gradients.
- `vgg16_finetune` / `resnet50_finetune`: same, but additionally re-enable gradients on the last convolutional block — `features[24:]` for VGG16, `layer4` for ResNet50. The 10× lower backbone learning rate is applied in `train.py` via parameter groups, not here.

```python
if cfg.model.endswith("_finetune"):
    head_params, backbone_params = [], []
    for name, param in model.named_parameters():
        if not param.requires_grad:
            continue
        (head_params if _is_head(name) else backbone_params).append(param)
    optimizer = torch.optim.AdamW(
        [
            {"params": head_params, "lr": cfg.lr},
            {"params": backbone_params, "lr": cfg.lr * 0.1},
        ],
        weight_decay=cfg.l2_lambda,
    )

        [p for p in model.parameters() if p.requires_grad],
        lr=cfg.lr,
        weight_decay=cfg.l2_lambda,
    )
```

**Urdu normalization rules** — applied in this order inside `normalize_urdu`:

1. `unicodedata.normalize("NFC", text)`
2. Character folding via `ARABIC_TO_URDU`: `ي→ی`, `ك→ک`, `ۀ→ہ`, `ة→ہ`, `أ إ آ→ا` (keep `آ` separate — it is a distinct Urdu letter, so it is *not* folded), `ى→ی`, Arabic-Indic digits `٠-٩` and `۰-۹` → ASCII `0-9`
3. When `strip_diacritics`, remove the combining marks `ً-ْ` and `ٰ`
4. Replace Urdu punctuation with spaced ASCII-adjacent forms: `۔` (full stop) and `،` (comma) each get surrounded by spaces
5. Collapse all whitespace runs to a single space and strip

**English normalization** — NFC, lowercase, spaces inserted around `.,!?;:"()` so punctuation becomes its own token, whitespace collapsed, stripped.

  - `src.q2_rnn.tokenizer.Vocab` with `__init__(self, itos: list[str])`, `__len__`, `encode(tokens: list[str]) -> list[int]`, `decode(ids: list[int], strip_specials: bool = True) -> list[str]`, `save(path: Path)`, and classmethods `build(sentences: Iterable[str], min_freq: int = 2) -> Vocab` and `load(path: Path) -> Vocab`.

    - `"enc_in"`: `LongTensor [B, S]`, right-padded with `PAD`
    - `"enc_len"`: `LongTensor [B]`, true source lengths
    - `"enc_mask"`: `BoolTensor [B, S]`, True at real tokens
    - `"dec_in"`: `LongTensor [B, T]`, `[SOS] + tgt`
    - `"dec_target"`: `LongTensor [B, T]`, `tgt + [EOS]`
    - `"dec_mask"`: `BoolTensor [B, T]`, True at real target positions
  - `src.q2_rnn.dataset.build_loaders(split_df, src_vocab, tgt_vocab, batch_size: int, num_workers: int, seed: int = SEED) -> tuple[DataLoader, DataLoader, DataLoader]`

**The shifting contract** — `dec_in` and `dec_target` are the same length `T = max_tgt_len + 1`, and position `t` of `dec_target` is what the model must predict after consuming position `t` of `dec_in`. For a target `[w1, w2]`: `dec_in = [SOS, w1, w2, PAD...]`, `dec_target = [w1, w2, EOS, PAD...]`. Getting this off by one is the single most common way to silently break a seq2seq model, which is why it has five dedicated tests.

```python
def collate_batch(batch):
    src_lists, tgt_lists = zip(*batch)
    src_lens = [len(s) for s in src_lists]
    tgt_lens = [len(t) + 1 for t in tgt_lists]  # +1 for SOS / EOS
    max_src, max_tgt = max(src_lens), max(tgt_lens)
    b = len(batch)

    enc_in = torch.full((b, max_src), PAD, dtype=torch.long)
    dec_in = torch.full((b, max_tgt), PAD, dtype=torch.long)
    dec_target = torch.full((b, max_tgt), PAD, dtype=torch.long)

    for i, (src, tgt) in enumerate(zip(src_lists, tgt_lists)):
        enc_in[i, : len(src)] = torch.tensor(src, dtype=torch.long)
        dec_in[i, 0] = SOS
        dec_in[i, 1 : len(tgt) + 1] = torch.tensor(tgt, dtype=torch.long)
        dec_target[i, : len(tgt)] = torch.tensor(tgt, dtype=torch.long)
        dec_target[i, len(tgt)] = EOS

    enc_len = torch.tensor(src_lens, dtype=torch.long)
    enc_mask = torch.arange(max_src)[None, :] < enc_len[:, None]
    dec_mask = torch.arange(max_tgt)[None, :] < torch.tensor(tgt_lens)[:, None]

    return {
        "enc_in": enc_in,
        "enc_len": enc_len,
        "enc_mask": enc_mask,
        "dec_in": dec_in,
        "dec_target": dec_target,
        "dec_mask": dec_mask,
    }
```

A source sentence that normalizes to zero tokens would make `pack_padded_sequence` fail later, so `TranslationDataset.__init__` asserts every row has at least one token on both sides — Task 9's filtering already guarantees it, and the assertion makes the guarantee load-bearing.

```python
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=PAD)
        self.dropout = nn.Dropout(dropout)
        self.rnn = nn.RNN(
            embed_dim, hidden_dim, num_layers=num_layers,
            nonlinearity="tanh", batch_first=True,
            dropout=dropout if num_layers > 1 else 0.0,
        )

    def forward(self, enc_in, enc_len):
        embedded = self.dropout(self.embedding(enc_in))
        packed = nn.utils.rnn.pack_padded_sequence(
            embedded, enc_len.cpu(), batch_first=True, enforce_sorted=False
        )
        _, hidden = self.rnn(packed)
        return hidden
```

`Decoder` mirrors it without packing — the decoder consumes `dec_in` in full and the loss mask handles padded positions — and ends with `nn.Linear(hidden_dim, vocab_size)`.

`Seq2SeqRNN.forward` runs the encoder, hands the hidden state to the decoder as its initial state, and returns the logits. Because `dec_in` already contains the gold prefix, this is full teacher forcing; the `teacher_forcing` config value is applied in `train.py` by mixing in sampled tokens, and is documented as such.

`greedy_decode` loops `max_len` times feeding back the previous argmax, starting from `SOS`, and tracks a `finished` boolean per row so that everything after the first `EOS` is written as `PAD`. The emitted sequence never contains `SOS` because the loop appends only predicted tokens.

```python
def masked_loss(logits, target, mask):
    flat_logits = logits.reshape(-1, logits.size(-1))[mask.reshape(-1)]
    flat_target = target.reshape(-1)[mask.reshape(-1)]

```

The epoch loop: forward, `masked_loss`, `backward`, `clip_grad_norm_(model.parameters(), cfg["grad_clip"])` capturing the returned pre-clip norm into the history so the report can show that exploding gradients were real and were controlled, then `optimizer.step()`.

Teacher forcing below 1.0 is implemented by running the decoder step-by-step and, at each step with probability `1 - teacher_forcing`, substituting the model's own previous argmax for the gold token in `dec_in`. At `teacher_forcing == 1.0` the fast batched path is used instead.

Perplexity is `exp(loss)`, clamped at 1e4 before logging so a diverging epoch cannot produce `inf` in the JSON. Checkpoint on best validation loss; early stop on the same; save to `out_dir / "best.pt"`; write `result.json` and `curves.png`.
